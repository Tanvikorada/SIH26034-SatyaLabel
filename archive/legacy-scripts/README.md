# Repository Archive

This folder contains historical debugging scripts, temporary one-off experiments, generated dumps, and earlier UI/logic prototypes that were used during iterative development.

The active application remains in:
- `backend/` — Express API + database + OCR logic
- `frontend/` — Next.js app and UI
- `docs/` — project documentation and rule references
- `setup.sh` / `setup.ps1` — local environment setup scripts
- `render.yaml` / `vercel.json` — deployment config

These archived files are intentionally kept out of the active code path to keep the repo clean and professional without changing the app behavior.
